# Publicación pública de Evolution Lab

Solicitud del usuario: publicar el contenido en Migueluckleo/Evolution-Lab y ocultar el correo corporativo encontrado en una exportación de Figma. Los originales locales se conservan; esta publicación comienza con un árbol nuevo y no transfiere el historial Git del repositorio original.

Se anonimizaron tres copias de texto y una entrada dentro de un ZIP. El contacto se reemplazó por una dirección de ejemplo no operativa. La copia de dependencias y el registro de fuentes apuntan al hash público; se conserva el hash de procedencia donde corresponde. [Manifiesto de transformaciones](output/evolution-lab/2026-10-16/publication-redactions.json). No se cambió una regla visual, token ni componente por esta transformación.

La búsqueda de patrones en 7198 textos no detectó claves privadas ni tokens comunes; es una comprobación acotada. Se inspeccionaron 2500 entradas de documentos/archivos y se ejecutó OCR local sobre 220 imágenes únicas, sin coincidencias del perfil objetivo y sin fallos de lectura en la ejecución final. No equivale a una certificación exhaustiva de ausencia de secretos o datos personales.

Los QA y manifiestos históricos describen los bytes y ejecuciones originales. No certifican retroactivamente una copia anonimizada. Los paquetes históricos con datos originales no se publican; el corte público genera paquetes nuevos con hashes propios. Caches, dependencias, carpetas temporales de compilación y el historial Git local no forman parte de la publicación.

Publicar GitHub no publica la biblioteca Figma ni concede permisos para editarla. Las protecciones adicionales del repositorio y la autenticidad de futuras entregas deben comprobarse al configurar su canal de publicación; este documento no afirma que ya estén habilitadas.

Los instaladores ZIP de ambas skills se entregan únicamente de forma local por instrucción posterior del usuario; no se incluyen en el commit público.
