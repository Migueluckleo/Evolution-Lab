# Prompt 02. Sintetizar un contrato cuando se entreguen fuentes

Utilizar después de integrar el paquete. Acompañar este prompt con los archivos reales o la URL y node ID fuente. La URL del archivo de reconstrucción no sustituye automáticamente una fuente de extracción.

```text
Aplica el protocolo 03-CONTRACT-SYNTHESIS.md a las fuentes que te entrego con este mensaje.

Lee AGENTS.md y los protocolos de ingesta, síntesis, trazabilidad y QA pertinentes. Localiza las fuentes reales. Si no son accesibles, registra lo que falta y pídeme el archivo o nodo concreto; no uses datos del ejemplo de Button como reemplazo.

Autorizo organizar las fuentes locales, redactar el contrato candidato, crear su reporte y actualizar los registros necesarios. Si adjunto un nodo Figma como fuente, autorizo su lectura y la de sus referencias pertinentes dentro del alcance indicado, pero ninguna escritura en Figma.

Determina si corresponde un contrato de foundations/tokens, componente u otra entidad. Usa la plantilla adecuada. Conserva nombres, IDs, valores, aliases, modos, scopes y description del JSON sin alterarlos. Referencia los datos canónicos en lugar de duplicarlos como otro catálogo editable.

Distingue lo explícito, derivado, observado, inferido, no resuelto y contradictorio. No inventes usos, variantes, reglas de interacción, accesibilidad o mapeos de código. Las inferencias deben aparecer como propuestas pendientes, no como requisitos demostrados.

Redacta requisitos candidatos con identificadores, fuentes y criterios verificables. Evalúa la cobertura, registra preguntas y señala qué faltante bloquea Figma o web. Un nodo aislado no demuestra toda una familia.

Entrega el contrato MD en DRAFT o IN_REVIEW, su reporte de síntesis y el resultado de QA documental. Identifica versión, fuentes y QA ejecutado; la revisión humana es opcional. Este encargo sigue siendo solo de síntesis: no inicia construcción por la delegación general.

No apruebes el contrato por mí. No crees páginas, variables ni componentes en Figma; no instales herramientas ni generes frontend. Si Graphify no está disponible o vigente, registra la limitación y continúa con las fuentes accesibles sin inventar hallazgos del grafo. No regeneres el grafo durante esta tarea.

Termina después de la entrega documental y espera mi aprobación explícita para esa versión y alcance.
```
