```tsx
import { typographyClass, typography, type TypographyId } from '@/index';
const titleStyle: TypographyId = 'heading-1-bold';
<h1 className={typographyClass(titleStyle)}>Título</h1>
```

Cada receta exporta `--ds-type-ID-family`, `-weight`, `-size`, `-line-height`, `-tracking` y `-font`. Para CSS de un componente, `font:var(--ds-type-ID-font)` consume la familia, peso, tamaño e interlineado; acompañarlo de `letter-spacing:var(--ds-type-ID-tracking)`. Las clases declaran `--ds-type-style-id` para inspección y handoff; el consumidor CSS debe declararlo también y comprobar las métricas efectivas. Usar referencias individuales cuando la composición requiera herencia parcial. No sustituir geometría, color ni decoraciones con estas recetas.

La conversión web conserva unidades: interlineado PERCENT → factor relativo; tracking PERCENT → em; PIXELS → px; interlineado AUTO → normal. La equivalencia visual de AUTO requiere comprobar la fuente cargada y el consumidor. Las referencias de tokens declaradas no acreditan por sí solas un binding Figma real.
